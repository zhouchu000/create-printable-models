# 从历史项目提取的经验

来源包括桌面显示设备外壳、手机/手表充电支架、带壳镜头保护盖，以及3MF逐件打印修改。这里保留经验的适用边界，供任何agent理解规则缘由。

| 历史现象或需求 | 转化成的可执行规则 | 边界 |
|---|---|---|
| 塑料柱与金属铜柱装配关系理解错，出现“套不上” | 先明确是套入、端面对接、压紧还是螺纹连接；画剖面并查装入路径 | 不能直接推导为加大孔径 |
| 杜邦线头太长导致后盖扣不上 | 占位模型包含塑料线头和弯折，检查闭盖过程 | 只知道线径不足以确定内腔 |
| 后盖不严、老卡扣易断 | 明确定位、扣合和受力部位；定义卡舌几何、释放方式，做局部试片 | 不存在已由这些记录证明的通用卡扣厚度或寿命 |
| 既要求外形美观，又要求加大出线口 | 审美和使用同时验收；线口按最大通过物确定 | 某一版出线口尺寸不能作为所有设备默认值 |
| 某版本要求结构最简单、易装且免买螺丝；另一个版本使用M2螺丝 | 固定方式跟随本次需求，控制零件数量和装配步骤 | 免螺丝不能成为所有模型的强制偏好 |
| 充电支架需要相机、表背和走线避让 | 完整占位包括接触面及凸起，检查发热部位和自然取放 | 外形预览不能证明磁吸、温升或稳定性 |
| 镜头盖用三档内径和侧面软衬试配 | 将间隙与衬层写成尺寸链，先测试小件 | 侧壁环不能验证全深摩擦与镜片顶部间隙 |
| PLA/PETG版本采用不同试制间隙 | 正式件与试装件共用参数，并按材料与方向复测 | 0.20/0.30 mm单边间隙属于特定试制设计，不作为通用公差 |
| 要求交付X2D可用3MF、必要支撑容易拆 | 交付真实对应配置，检查路径和支撑；说明零件用途 | 一盘混材测试的温度和冲洗量不推广为通用工艺 |
| 逐件打印仅修改打印顺序字段 | 保留原工程，重切片后检查机器净空和顺序 | 归档结构未变不等于打印路径已验证 |

本Skill补充的工程方法包括：集中参数、CAD导出重读、独立网格检查、来源追踪和分层验收。这些是用于执行和验证的方法，不冒充用户逐项指定的偏好。
