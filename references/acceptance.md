# 验收与交付

验收对象是最终交付文件。源码、导出文件、预览与切片必须对应同一个版本。

## A. 生成与可复现

- 运行完整源码，记录退出状态和工具版本；导出的零件数量与约定相符。
- 从空输出目录重建成功；不要依赖手工遗留的中间零件。
- 关键参数集中，明确 mm、原点、轴向、正面与装配位置。
- 若只提供源码且未执行，状态写明，不把代码片段称为已生成模型。

## B. 数字几何

实体 CAD：逐件检查实体有效、体积为正、独立实体数量；STEP导出后重新读入。外尺寸、内部净空、孔径、间隙和安装坐标对照任务约定。

网格：检查非空、坐标有限、尺寸正确、闭合、面方向一致、无退化三角形、预期连通体数量。可用包内工具：

```sh
python scripts/inspect_stl.py body.stl --expect-size 80 60 33 --expect-bodies 1 --on-bed --output body-check.json
```

上面尺寸只是命令示例。每个文件用它自己的预期尺寸；不能照抄。

打印摆放的STL逐件检查最低Z在0附近；旋转后按实际包围盒落床，不能用零件高度代替平移量。`--on-bed` 使用 `--size-tol` 作为落床容差。装配坐标的STEP/STL不要求落床。

连通、闭合和体积通过，仍不能证明没有自交、壁厚合理、内腔可达或装配正确。另用CAD剖面、交集、尺寸查询和视觉核对检查功能部位；卡扣寿命和实际配合归入实物验证。

装配：检查配合件最终相对位置、插入/拆卸路径、连接器和线束、操作空间。交集检查要区分有意的弹性干涉和错误碰撞。禁止为了得到“零干涉”删除真实占位物或功能结构。

布尔交集运算异常必须让该检查失败或标记未完成；不能捕获所有异常并返回0。只对成功执行得到的空交集记0；计算得到无效或非有限体积时同样失败。

预览：从最终CAD/网格生成至少外观和内部两种视角；多件产品增加装配或拆解视图。检查圆角、开口、零件连通和比例；美化渲染不能改变模型形状来掩盖错误。

## C. 切片与打印工程

切片器存在且任务需要3MF时：

1. 使用已核实的机器、喷嘴、材料、打印板及打印模式配置。
2. 核对单位、打印方向、零件数量、接地、床外对象、材料/喷嘴映射。
3. 查看首层和关键层：薄壁是否生成、孔是否贯通、是否有空中起印、支撑接触和拆除路径。
4. 有多材料时核对换料和冲洗塔；逐件模式检查机器活动净空和顺序。
5. 保存工程，重开最终3MF，重新切片并核对警告。保留原生工程需要的关系和元数据。
6. 报告估算时间/耗材时写清“切片估计”；对未解决警告列出对实际使用的影响。

没有切片器或正确配置时，交付模型并标记“未切片”。几何3MF、带配置的工程3MF与含已切片路径的3MF分清楚；只打包STL和XML不能称为已切片的可打印工程。

修改已有3MF：先备份并检查ZIP成员、对象关系、单位和变换。比较修改前后，确认仅目标字段/几何改变。几何、摆放、模式或打印设置改变后，旧G-code不再作为本版本的可执行路径；保留源工程并由原切片器重新生成。

## D. 实物

只有实际执行并得到观察结果，才能标记打印、试装、支撑拆除、扣合、倾倒稳定、充电温升或耐久性通过。让用户试装时给可操作的通过标准。真实打印任务需要用户本次授权或已有有效授权。

## 最小交付布局

按任务裁剪，避免重复多套难以分辨的正式文件：

```text
model/
  source/             参数化源文件、依赖及复现命令
  parts/              独立零件STL，适用时附STEP
  previews/           由最终模型生成的外观/内部/装配图
  fit/                需要时的试装件及编号参数表
  project.3mf         用户要求且有相应验证时
  verification.json   实际检查结果与未执行项
  使用说明.md         选哪个文件、装配顺序、试装标准
```

`verification.json` 至少记录：版本/单位、参数来源、零件及尺寸、工具版本、生成状态、几何检查、配合/路径检查、切片状态、实物状态、未解决事项。状态用 `passed / failed / not_run / partial`；失败包含具体特征和下一步需要的数据。不要把缺失检查默认成通过。
